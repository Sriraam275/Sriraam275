Show Image

Problem: Every release meant someone manually building, pushing, and restarting services — slow, error-prone, and impossible to scale as a habit.

What I built:

A Jenkins pipeline on AWS EC2, triggered automatically via GitHub webhooks on every push

🔒 Secure & Scalable AWS VPC Network Architecture

Show Image

Problem: A flat network puts backend and database resources one misconfiguration away from being exposed directly to the internet — not a risk worth taking.

What I built:

A custom VPC with public and private subnets, using an Internet Gateway and NAT Gateway to control outbound traffic in one direction only
A layered security model with Security Groups and NACLs at both instance and subnet level
Validated the design with a public-facing web server and a fully isolated private backend — confirmed zero direct internet exposure for backend resources

AWS VPC EC2 IGW NAT Gateway Security Groups NACLs
